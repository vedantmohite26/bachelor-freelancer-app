## 2026-06-25 - [Flutter rendering and async source optimization]
**Learning:** Using `shrinkWrap: true` on a `ListView` inside a `SingleChildScrollView` is a performance anti-pattern in Flutter as it disables list virtualization, forcing the layout of all items at once (O(N) vs O(visible)). Additionally, creating Streams or Futures directly inside the `build` method (or within a `StreamBuilder`/`FutureBuilder` in `build`) causes redundant subscriptions or API calls on every widget rebuild.
**Action:** Replace `SingleChildScrollView` + `Column` + `ListView(shrinkWrap: true)` with `CustomScrollView` using `SliverToBoxAdapter` for static content and `SliverList` for dynamic lists. For async data, convert the widget to a `StatefulWidget`, cache the Stream/Future in `initState`, and handle updates in `didUpdateWidget` only when relevant dependencies change.
