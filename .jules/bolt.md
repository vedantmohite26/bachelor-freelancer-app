## 2026-11-20 - List Virtualization in Rating Reviews List
**Learning:** Using SingleChildScrollView + Column + ListView.builder(shrinkWrap: true) is a major performance anti-pattern in Flutter because it disables list virtualization and forces Flutter to construct and layout all list elements immediately, causing O(n) rendering overhead. Refactoring the scroll view to CustomScrollView with SliverToBoxAdapter, SliverFillRemaining, and SliverList under a unified StreamBuilder restores viewport-bounded lazy virtualization (O(1)), dramatically reducing initial widget build latency for long lists of reviews.
**Action:** Always eliminate shrink-wrap nested ScrollViews in favor of CustomScrollView and specialized Slivers (e.g. SliverPadding, SliverList) to guarantee lazy rendering and perfect viewport performance across all list screens.
