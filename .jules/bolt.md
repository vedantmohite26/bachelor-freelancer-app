## 2026-06-25 - [Virtualization Refactor Patterns]
**Learning:** When refactoring a `StreamBuilder` that previously returned a `ListView` (nested inside a `SingleChildScrollView` with `shrinkWrap: true`), the most efficient approach is to move the `StreamBuilder` to wrap the entire `CustomScrollView`. This allows for dynamic slivers (e.g., using `SliverList.builder` for data and `SliverFillRemaining` for status placeholders) which enables full list virtualization and maintains a consistent scrolling experience across the entire screen.
**Action:** Always wrap the `CustomScrollView` (or return it from the builder) when handling asynchronous data streams that feed into lists, ensuring that static components are placed in `SliverToBoxAdapter` and list data is virtualized via `SliverList` or `SliverFixedExtentList`.
